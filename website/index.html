NexaTerm 1.0.0 · ฟรีและโอเพนซอร์ส (MIT) · Windows 10 และ 11

หนึ่งพื้นที่ทำงาน
ครบทุกการเชื่อมต่อระยะไกล

เทอร์มินัล, SSH, SFTP, SSH tunnel และเครื่องมือตรวจสอบเครือข่ายสำหรับผู้ดูแลระบบ รวมอยู่ในโปรแกรมเดียวบน Windows ไม่ต้องสมัครบัญชี ไม่มีรุ่นเสียเงิน และไม่ส่งข้อมูลการใช้งานออกจากเครื่อง

ดาวน์โหลดสำหรับ Windows ดูวิธีใช้งาน

ติดตั้งแบบรายผู้ใช้ ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ หรือใช้รุ่นพกพาที่ไม่ต้องติดตั้งเลย

ใช้ได้ฟรีทุกฟังก์ชัน

สัญญาอนุญาต MIT ไม่มีรุ่นเสียเงิน ไม่มีคีย์ลิขสิทธิ์ และไม่จำกัดจำนวน session หรือ tunnel

ไม่เก็บข้อมูลการใช้งาน

ไม่มี telemetry และไม่เชื่อมต่ออินเทอร์เน็ตเองตอนเปิดโปรแกรม ข้อมูลทุกอย่างอยู่ในเครื่องคุณ

รหัสผ่านอยู่ใน Windows

เก็บใน Windows Credential Manager ไม่อยู่ในฐานข้อมูลของโปรแกรม ไฟล์ log หรือไฟล์ที่ export ออกไป

ตรวจ host key ทุกครั้ง

เซิร์ฟเวอร์ใหม่ต้องยืนยัน fingerprint SHA-256 ก่อน ถ้า key เปลี่ยน โปรแกรมจะไม่เชื่อมต่อจนกว่าคุณตัดสินใจ

ความสามารถ

งานที่ผู้ดูแลระบบทำทุกวัน อยู่ในหน้าต่างเดียว

เปิดหลายเทอร์มินัลในแท็บเดียว

แบ่งหน้าจอได้ 2 หรือ 4 ช่อง แล้วลากเส้นแบ่งเพื่อปรับขนาด ใช้ PowerShell, Command Prompt, Git Bash, WSL และ SSH ร่วมกันได้ในแท็บเดียว โปรแกรมตรวจหา shell ที่ติดตั้งไว้ในเครื่องให้เอง

  • รองรับสี 256 สี, truecolor และ Unicode
  • ค้นหาข้อความในเทอร์มินัล, export ผลลัพธ์ และบันทึก log ลงไฟล์
  • ปรับฟอนต์, เคอร์เซอร์ และชุดสีของเทอร์มินัลได้

จัดการไฟล์บนเซิร์ฟเวอร์ด้วย SFTP

เปิด SFTP จาก SSH ที่เชื่อมต่ออยู่ได้ทันทีโดยไม่ต้องล็อกอินซ้ำ ลากไฟล์จาก File Explorer มาวางเพื่ออัปโหลด ดูความคืบหน้าและยกเลิกได้ ไฟล์ที่ส่งไม่ครบจะถูกลบทิ้ง ไม่ค้างอยู่บนเซิร์ฟเวอร์

  • สร้าง, เปลี่ยนชื่อ, ลบไฟล์และโฟลเดอร์ โดยถามยืนยันก่อนลบหรือเขียนทับ
  • แก้ไฟล์ข้อความบนเซิร์ฟเวอร์ในโปรแกรม: บันทึกลงไฟล์ชั่วคราวก่อนแล้วจึงแทนที่ไฟล์เดิม ถ้าบันทึกไม่สำเร็จ ไฟล์เดิมยังอยู่ครบ
  • ส่งไฟล์ใหญ่แบบทยอยอ่าน ไม่โหลดทั้งไฟล์เข้าหน่วยความจำ

สั่งงานหลายเซิร์ฟเวอร์พร้อมกัน

เลือกเทอร์มินัลที่จะรับคำสั่ง แล้วพิมพ์ครั้งเดียว ก่อนส่งจะมีหน้าต่างยืนยันที่แสดงรายชื่อเครื่องปลายทางทั้งหมด ช่องที่ถูกเลือกมีกรอบสีเหลืองให้เห็นชัดตลอดเวลา

  • คำสั่งที่อาจทำความเสียหาย เช่น rm -rf, mkfs, reboot หรือ DROP TABLE จะมีคำเตือนสีแดง
  • โหมดพิมพ์พร้อมกัน: ทุกปุ่มที่กดในช่องหนึ่งถูกส่งไปยังช่องอื่นที่เลือกไว้ด้วย

ยืนยันตัวตนเซิร์ฟเวอร์

แสดง fingerprint SHA-256 ก่อนเชื่อมต่อเซิร์ฟเวอร์ใหม่ทุกครั้ง ไม่มีตัวเลือก "เชื่อทุกเครื่อง" ให้กดข้าม

SSH tunnel

ส่งต่อพอร์ตแบบ local (-L), remote (-R) และ SOCKS5 (-D) เริ่ม หยุด หรือเริ่มใหม่ได้ แจ้งเตือนเมื่อพอร์ตถูกใช้อยู่แล้ว

จัดการ SSH key

สร้าง key แบบ Ed25519 หรือ RSA พร้อมรหัสผ่าน นำเข้า key เดิม คัดลอกหรือ export public key และเปลี่ยนรหัสผ่านของ key ได้

ชุดคำสั่งที่ใช้บ่อย

บันทึกคำสั่งแยกหมวด ใส่ตัวแปรแบบ {{service}} ให้โปรแกรมถามค่าตอนใช้ และแสดงคำสั่งเต็มให้ดูก่อนส่งทุกครั้ง

เครื่องมือเครือข่าย

Ping, Traceroute, DNS, Reverse DNS, ทดสอบพอร์ต TCP และดูข้อมูลการ์ดเครือข่าย ทุกอย่างทำงานเมื่อคุณกดเท่านั้น และยกเลิกกลางคันได้

รายละเอียดอื่นๆ

  • ล็อกอินด้วยรหัสผ่าน, private key, SSH agent ของ Windows หรือ keyboard-interactive
  • เชื่อมต่อผ่านเครื่องกลาง (ProxyJump)
  • จัด session เป็นโฟลเดอร์ ใส่แท็ก ค้นหา และนำเข้าจาก ~/.ssh/config
  • สำรองและกู้คืนข้อมูลได้จากหน้าตั้งค่า
  • ธีมมืดและธีมสว่าง

วิธีใช้งาน

เริ่มต้นใช้งานใน 6 ขั้นตอน

  1. ติดตั้งหรือแตกไฟล์

    ดับเบิลคลิก NexaTerm-Setup-x64.exe แล้วทำตามตัวช่วยติดตั้ง หรือแตกไฟล์ NexaTerm-Portable-x64.zip แล้วเปิด NexaTerm.exe ได้เลย

  2. เปิดเทอร์มินัลบนเครื่อง

    กด Ctrl + T เพื่อเปิด shell เริ่มต้น หรือกดลูกศรข้างปุ่มเทอร์มินัลบนแถบเครื่องมือเพื่อเลือก PowerShell, Command Prompt, Git Bash หรือ WSL

  3. เพิ่ม session SSH

    กด Ctrl + Shift + N ใส่ชื่อเครื่อง พอร์ต ชื่อผู้ใช้ และวิธีล็อกอิน ถ้าใส่รหัสผ่านไว้ รหัสจะถูกเก็บใน Windows Credential Manager หรือเว้นว่างไว้ให้โปรแกรมถามตอนเชื่อมต่อก็ได้

  4. เชื่อมต่อครั้งแรก

    ดับเบิลคลิก session ในแถบด้านซ้าย โปรแกรมจะแสดง fingerprint ของเซิร์ฟเวอร์ ให้เทียบกับค่าที่ผู้ดูแลเซิร์ฟเวอร์ให้มา ถ้าตรงกันจึงกด "Trust and connect"

  5. เปิด SFTP

    ขณะอยู่ในเทอร์มินัล SSH ให้กดปุ่ม SFTP บนแถบเครื่องมือ หรือคลิกขวาที่ session แล้วเลือก "Open SFTP browser" ลากไฟล์มาวางเพื่ออัปโหลด ดับเบิลคลิกไฟล์ข้อความเพื่อแก้ไข

  6. แบ่งหน้าจอและสั่งงานหลายเครื่อง

    คลิกขวาที่ session แล้วเลือก "Connect in split pane" เพื่อเปิดในช่องใหม่ จากนั้นกดปุ่ม multi-execution บนแถบเครื่องมือ เลือกเครื่องปลายทาง พิมพ์คำสั่ง แล้วกด Broadcast

คำถามที่พบบ่อย

ใช้ฟรีจริงไหม มีเงื่อนไขอะไรบ้าง

ฟรีทุกฟังก์ชัน เผยแพร่ภายใต้สัญญาอนุญาต MIT ใช้งานส่วนตัวหรือในองค์กรได้ แก้ไขและนำไปแจกจ่ายต่อได้ ไม่มีรุ่นเสียเงินและไม่มีระยะทดลองใช้

โปรแกรมส่งข้อมูลอะไรออกไปบ้าง

ไม่ส่งข้อมูลการใช้งานใดๆ ไม่มี telemetry และไม่ตรวจหาอัปเดตเอง การเชื่อมต่อออกไปข้างนอกเกิดขึ้นเฉพาะเมื่อคุณเชื่อมต่อเซิร์ฟเวอร์ หรือกดปุ่ม "Public IP" ในหน้าเครื่องมือเครือข่าย

ต้องใช้สิทธิ์ผู้ดูแลระบบไหม

ไม่ต้อง ตัวติดตั้งติดตั้งให้เฉพาะผู้ใช้ปัจจุบัน (ค่าเริ่มต้นคือ %LOCALAPPDATA%\NexaTerm) ส่วนรุ่นพกพาไม่ต้องติดตั้งเลย

WebView2 คืออะไร ต้องติดตั้งเพิ่มไหม

WebView2 เป็นส่วนประกอบของ Microsoft ที่ NexaTerm ใช้แสดงหน้าจอ Windows 11 และ Windows 10 ที่อัปเดตแล้วมีอยู่แล้ว ถ้าเครื่องยังไม่มี ตัวติดตั้งจะติดตั้งให้ ส่วนรุ่นพกพาต้องติดตั้ง WebView2 เองก่อน

ย้ายรุ่นพกพาไปเครื่องอื่น รหัสผ่านไปด้วยไหม

ไม่ไป เพราะรหัสผ่านเก็บใน Windows Credential Manager ของผู้ใช้แต่ละคน Session, โฟลเดอร์, การตั้งค่าและ known hosts ย้ายไปพร้อมโฟลเดอร์ portable-data\ แต่โปรแกรมจะถามรหัสผ่านใหม่บนเครื่องใหม่

รองรับ RDP, VNC, X11, Telnet หรือ Serial ไหม

ยังไม่รองรับในรุ่น 1.0.0 และโปรแกรมจะไม่แสดงตัวเลือกเหล่านี้จนกว่าจะใช้งานได้จริง แผนงานอยู่ใน DEVELOPMENT_STATUS.md

เกี่ยวข้องกับโปรแกรมเชิงพาณิชย์ตัวอื่นไหม

ไม่เกี่ยวข้อง NexaTerm เป็นโปรเจกต์อิสระที่เขียนขึ้นใหม่ทั้งหมดด้วย Rust และ TypeScript ไม่มีโค้ดหรือไฟล์ภาพจากโปรแกรมอื่น

สำหรับนักพัฒนา

สร้างด้วยอะไร

Tauri 2 และ Rust

งานที่ต้องใช้สิทธิ์ของระบบ เช่น เปิด process, เชื่อมต่อเครือข่าย และอ่านเขียนไฟล์ ทำในฝั่ง Rust ทั้งหมด หน้าจอเรียกใช้ผ่านคำสั่งที่ตรวจสอบข้อมูลแล้วเท่านั้น

russh และ russh-sftp

ไลบรารี SSH และ SFTP ที่เขียนด้วย Rust ทั้งหมด ทำงานแบบ async บน Tokio ไม่ต้องพึ่ง OpenSSL

ConPTY และ xterm.js

เทอร์มินัลบนเครื่องใช้ Windows ConPTY ผ่าน portable-pty ส่วนการแสดงผลใช้ xterm.js

SQLite

ข้อมูลทั้งหมดอยู่ในไฟล์ SQLite ไฟล์เดียว มีระบบ migration สำหรับอัปเกรดรุ่น

git clone https://github.com/bom-sudo/NexaTerm.git && cd NexaTerm && npm ci && npm run tauri dev

ต้องใช้ Node.js 22 ขึ้นไป, Rust และ C compiler รายละเอียดอยู่ใน docs/DEVELOPER.md
